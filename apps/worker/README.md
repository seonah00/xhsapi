# 기존 공유주소 복구 워커

`note_link_recovery`는 관리자가 명시적으로 접수한 기존 Apify 결과의 GET 전용 조회입니다. 기존 `APIFY_TOKEN`을 사용하며 새 Actor 실행·비용 견적·예산 예약·정기 수집 활성화를 하지 않습니다. 실행 직전 관리자 재직·조직·중지 설정을 확인합니다.

검색/상세 Actor 완료 실행을10개씩 읽고, 현재 조직과 모드의 동일 게시물ID에만 연결합니다. 원래 수집시각을 유지하며 더 오래된 주소로 덮어쓰지 않습니다. 공유주소는 게시물 삭제 시 함께 삭제되고, 보관이 외부 열림 성공을 뜻하지는 않습니다. 작업 결과에는 집계만 남깁니다. 실패/불명 상태의 유료 작업을 다시 실행하지 않습니다.
