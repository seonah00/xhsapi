# 허가·증빙 조건 제거 검증

사용자 지시에서 도출한 시나리오: 별도 허가/증빙 없이 견적과 실행 확인으로 검색·표지 보완, 기존 비용 제한과 조직 격리 유지.

- RED: providers.test.ts의 null/철회/만료된 허가 3건이 실제 실행되어 실패. 커밋 a5fac6f.
- GREEN: 같은 테스트 포함 단위 134건 통과. 타입 검사·린트 통과.
- DB: Apify 허가 없는 조직에서 견적→예약→가짜 API→저장→조회, 다른 조직 읽기 차단, 만료 숨김·삭제, 동의 철회·예산 소진·중지 차단을 검증한다.
- E2E: 관리자 승인 양식 없음, 비용 확인 안내와 중지 스위치 동작 검증.
- 실제 공급자 API를 이번 코드 검증에서 호출하지 않는다.
- CI 37579479799 (259b5fd): 단위 134건, native PostgreSQL 통합 137건, 브라우저 E2E 15건 모두 통과. 커버리지 비율은 측정하지 않았다.
- Railway 워커의 감시 경로가 공유 패키지 변경을 감지하지 않아 첫 배포가 생략됐다. ADR 0015에 맞춰 워커 진입점의 설명을 갱신하고 같은 검증 코드를 다시 배포한다.
