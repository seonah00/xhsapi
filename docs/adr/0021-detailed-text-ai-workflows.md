# ADR 0021: 상세 텍스트 분석 → 기획 초안 → 성과 회고

2026-10-07 사용자 요청 및 후속 우선순위 선택에 따른다. 영상 업로드 없이 현재 제목·본문·태그를 자세히 분석한다.

## 레퍼런스

상세 결과 v2는 주제, 예상 독자, 제목/첫 문장, 본문 전개, 핵심 문구, 태그, 행동 유도, 내 콘텐츠 적용의 8개 항목을 반드시 반환한다. 각 항목은 관찰/추론/제안과 실제 입력 필드 근거를 가진다. 원문 인용은 해당 입력의 부분 문자열인지 서버에서 검사하고 한국어 뜻·표현 역할을 함께 표시한다. 본문이나 태그가 없으면 해당 항목은 자료 부족으로 표시한다. 촬영·편집·음악·영상 자막/대사는 분석하지 않는다. 기존 v1 결과는 그대로 표시한다.

## 기획

저장한 사실 입력(대상, 확인 사실, 촬영 가능한 장면), 계정 방향, 선택한 본인 레퍼런스 제목·태그 및 live 분석의 해석/적용 제안을 사용한다. 사실이 부족하면 과금 전에 입력을 요청한다. 레퍼런스·게시물의 내부 UUID와 URL은 AI 입력에서 제외하고 alias만 사용한다. 분석은 신뢰하지 않는 참고 자료이며 사용자 경험으로 승격하지 않는다. 중국어 제목 후보·본문·자막 초안, 한국어 의미·촬영 제안·확인 질문을 별도 제안 버전으로 저장한다. 입력에 없는 아라비아 숫자, 잘못된 근거, 협찬 표시 누락을 검사한다. 촬영 목록은 새 기획 제안이다. 생성 중 사실 입력이 바뀌거나 이후 적용 시 사실이 다르면 적용하지 않는다. 자동 저장 시 레퍼런스 연결을 보존한다.

## 성과

본인 계정의 게시물당 스냅샷 1개, 최대 20개만 사용한다. 수치 관찰은 기존 서버 계산을 유지하고 AI는 근거가 있는 가설과 다음 실험(바꿀 것, 유지할 조건, 측정 지표, 시점)을 반환한다. 누락 지표를 0으로 바꾸지 않는다. 표본 부족, 프로모션, 서로 다른 관찰 경과 시간 등을 명시하며 인과관계나 개선율을 보장하지 않는다. 계정 방향은 자동 변경하지 않는다.

## 비용·실행

세 작업 모두 OpenAI AI01 텍스트 요청 경로를 사용한다. 모델별 검증 단가, 실행 스위치, 조직 AI 스위치, 요청별 전송 동의, 예산 예약, 소유권을 확인한다. 작업별 전송 범위를 화면에 구분한다. 입력 JSON은 12KB, 출력은 최대 6,000 토큰이다. 단가는 입력 최대 20,000 + 출력 6,000 토큰을 커버해야 한다.

마이그레이션 23은 price version에 output_token_limit을 추가하고 기존 OpenAI 가격을 2,000으로 기록하며 단가를 미확인으로 돌린다. 기존 저비용 견적으로 새 출력을 실행할 수 없도록 견적과 워커 양쪽에서 가격 버전의 출력 상한을 검사한다. 단가 CLI는 --output-token-limit 6000 이상을 요구한다. 과거 USD 0.0112 실검증 단가는 새 출력 상한의 검증 가격이 아니다. 운영 가격 재등록/예산 승인 없이 자동 활성화하지 않는다.

발송 전 마커를 저장하고, 응답 유실·거부·잘못된 응답은 unknown_outcome으로 남기며 재호출하지 않는다. 기획/회고도 동일하게 적용한다. 성공 정산액은 앱의 보수적 상한이며 OpenAI 실청구서 금액이 아니다.

이번 개발 검증은 합성 자료/가짜 fetch만 사용하며 추가 유료 API 호출은 하지 않는다.
