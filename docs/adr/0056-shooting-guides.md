# 0056 컷별 촬영 가이드와 개인 촬영 체크

2026-10-26 사용자 승인: 더우인 제외, 뷰티/패션/카페/브이로그/맛집부터 컷별 안내 → 촬영 체크 → 글쓰기 연결, 관리자 검토 후 공개. 예산·신규 유료·수집·정기 실행은 보류.

기존 case_guides.content에 선택적 shooting 구조를 추가하여 이전 가이드와 호환한다. 5종×7컷 기본안은 작성 도구이며 검토 완료 자료가 아니다. 관리자는 준비/편집/각 컷의 목적·구도·카메라 위치·행동·권장 원본 확보 시간·중한 자막 예시·대안을 편집하고 기존 검토 절차로 공개한다. 수정하면 다시 비공개다. 실제 게시물 성과를 주장하거나 남의 미디어를 복제하지 않는다.

shooting_work는 조직/사용자/모드별 개인 기록이다. 시작 시 DB 트리거가 공개된 가이드와 검토 버전을 복사한다. 사용자에게 snapshot 열 수정 권한을 부여하지 않는다. 기존 개인 작업은 이후 가이드 편집/비공개 전환에도 당시 저장본으로 유지한다. 기수 강사·관리자에게 개인 메모를 공개하지 않으며 사용자 삭제 처리에도 포함한다.

수동 저장과 revision 비교로 동시 수정 충돌을 표시한다. 미저장 변경은 글쓰기 가져오기를 막고, 미촬영 필수 컷을 기록한다. 촬영한 컷의 개인 메모/후기만 기존 새 글 임시 메모에 추가하며 제목/본문/한국어/태그를 덮어쓰지 않는다. 같은 메모가 현재 임시본에 있으면 중복 추가하지 않는다. 샘플 자막은 실제 경험처럼 자동 삽입하지 않는다.
