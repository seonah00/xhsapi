# 0028. 월간 학생 한도와 실제 문맥 점검

2026-10-12 사용자 요청으로 일별 횟수 제한을 한국 시간 달력 월 기준으로 전환한다. 검색·AI·음성 기본값은 기존 30일분(300·600·150), 사전 AI는 월 90회다. 자동 검색의 기존 승인 기간·스위치와 건당/조직 금액 예산은 유지한다. 사전 전체 월 5 USD 비용 상한도 유지하므로 개인 횟수는 보장량이 아니다.

마이그레이션 27은 기존 설정을 30배로 옮기고 reserve_and_enqueue에서 사용자·기능별 advisory lock 뒤 월 횟수를 재검사한다. idempotency replay는 재차감하지 않는다. 사전 SQL 반환 필드/에러 이름은 롤링 배포 호환을 위해 유지하되 집계 기간은 월이다.

실제 문맥 점검은 OpenAI 기존 AI01 가격·동의·예약 흐름을 사용한다. 저장된 본인 기획 버전과 사실만 12KB 이내로 전송한다. 정확한 원문 구간을 검증하며 중복 구간은 자동 적용하지 않고 새 숫자는 거부한다. 발송 이후 불명 결과는 재전송하지 않는다. 규칙 결과는 AI 실패에도 남긴다.

예산 화면은 선택 월과 겹치는 모든 기간 및 현재 사용 가능 여부를 표시한다. 기간이 지난 잔액을 현재 예산으로 오해하지 않게 한다.
