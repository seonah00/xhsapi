# ADR0046 — 게시물 수명 동안 공유주소 보관·기존 Apify 결과 복구

2026-10-21 사용자 승인: 공유주소를 게시물과 함께 계속 보관하고 기존 결과에서 복구. 예산증액·새유료수집·정기수집활성화 금지. ADR0020/0030/0037의 공유주소24시간보관만 대체한다. 미디어·원문발췌의TTL, 외부실행비용게이트는 유지한다.

- 별도 서비스전용 note_access_links의 expires_at=NULL은 게시물수명. ON DELETE CASCADE·RLS·직접조회금지·인증/조직/모드검사·토큰 비노출 유지. 명시적인 유한 만료는 철회/테스트 용도로 존중한다.
- observed_at은 실제 수집완료시각. 보관복구는 원래시각을 유지하고 새검증으로 간주하지 않는다. 더 오래된 결과나 같은시각의 반복결과는 최근주소를 덮어쓰지 않는다. 기존행은 구TTL에서24시간을뺀 수집시각추정으로 이관한다. 이미삭제된주소는 migration으로 되살리지 못한다.
- 관리자 /admin/original-links에서 고정 Zen 검색/상세Actor의 SUCCEEDED 실행만 최대10개씩 GET. dataset필드는id/url/xsec_token만 읽고 실행당최대1000행. POST/재실행/unknown_outcome/자동반복/미디어다운로드 없음. 동일조직·모드·보관중인 동일ID 게시물만 upsert. 다른결과를 원래대상복구로 집계하지 않는다. 결과/로그/브라우저에는 집계만 반환한다.
- 링크보유는 열림검증성공이 아니다. 샤오홍슈 로그인/삭제/공유주소변경은 여전히 영향을 준다. 기본주소/제목검색을 복구로 취급하지 않는다. 현재열림을 자동검증하거나 로그인제한을 우회하지 않는다.
- 반복GET은 기존결과 조회이며 새스크래퍼실행비용을 만들지 않는다. 공급자저장소조회/트래픽은 공급자계약에 따르며 비용설정은 변경하지 않는다.

운영키는 worker에만 있으므로 웹은 관리자 요청을 note_link_recovery 작업으로 접수한다. 비용견적/원장예약이 없는 GET전용 작업이며 소유자·조직·모드·source·offset로 중복 방지한다. 워커가 실행 시 관리자 재직과 조직상태/kill스위치를 다시 확인한다. 키를 웹으로 복사하지 않는다. 완료/실패 작업은 자동 재접수하지 않으며, 대시보드는 작업의 집계만 표시한다. 유료 수집 작업이나 기존 unknown_outcome은 재실행하지 않는다.

검증: 보관24시간경과·cleanup·삭제cascade·구결과덮어쓰기방지·조직격리, GET-only/학생금지/모의모드외부0·원문302/클립보드·철회안내.
