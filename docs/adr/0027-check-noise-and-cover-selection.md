# 0027 — 기본 문구 점검의 범위와 반복 경고

숫자만으로 사실 주장을 판정하지 않는다. 가격/기간/수량 단위가 있는 아라비아 숫자를 비교하며, 이는 사실 검증이 아니다. 한자 수량과 복잡한 문맥은 범위 밖이다. 같은 필드의 반복 기본 경고는 첫 UTF-16 위치를 유지하고 횟수를 표시한다. 편집 규칙의 개별 수정 제안은 위치별로 보존한다.

붙여넣기 코드 의심 표시는 자동 삭제하지 않고 원문 대조를 안내한다. 실제 AI 문맥 교정은 미구현이므로 live 화면에서 요청을 제공하지 않는다. 과거 점검 기록은 불변으로 유지한다.

표지 URL이 없거나 형식 오류인 경우 접근 정책을 통과해 조회된 대체 URL을 사용한다. CDN t 파라미터로 만료를 추정하지 않으며 403 우회/미디어 다운로드/임의 유료 갱신은 하지 않는다.
