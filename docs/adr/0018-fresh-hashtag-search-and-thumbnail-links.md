# ADR 0018: 새 해시태그 검색과 썸네일 원문 링크

2026-10-07 사용자 요청: 썸네일 클릭으로 해당 게시물을 열고, 탐색에서 해시태그마다 새 결과를 조회한다.

- 안전성 검사를 통과한 실제 원문 URL을 썸네일 링크로 사용한다. 새 탭, noopener/noreferrer, 키보드 포커스와 접근성 이름을 제공한다. 데모 주소는 링크하지 않는다. 공급자 원문에 접근 토큰이 없으면 샤오홍슈 측 접근이 제한될 수 있다.
- 검색창의 기본 동작은 새 게시물 검색 견적이다. 별도 저장 자료 검색은 무료 GET으로 유지한다. 검색어 양 끝의 #/＃를 제거하고 같은 정규화를 저장 검색과 공급자 조회에 적용한다.
- 견적·동의·예약·페이지 상한은 유지한다. 입력/페이지 새로고침만으로 유료 API를 호출하지 않는다. 같은 견적 재전송은 기존 멱등 처리와 단일 사용 제약으로 중복 과금하지 않는다.
- 완료된 새 검색은 이번 작업이 반환한 게시물만 표시한다. 작업 ID는 현재 조직·사용자·모드·작업 유형을 검증하며 타인의 결과 목록을 읽지 않는다. 전체 저장 자료는 무료 검색으로 다시 탐색할 수 있다.
- 작업 완료 시 화면이 자동 갱신된다. 이미 반환된 게시물이 다시 검색될 수 있으므로 매번 서로 다른 게시물을 보장하지 않는다.

검증: 해시태그 정규화 단위 테스트, 작업별 결과 격리 DB 테스트, 새 검색 완료 E2E, 썸네일 새 탭 이동 E2E. 공급자와 이미지/원문 요청은 합성 응답으로 검증한다.
