# 0043 임시 저장 복원과 개인 사전 편집

2026-10-20. 사용자는 임시 저장·복원 → 사전 수정·분류 → 사용법·예문 저장을 요청했다. 예산 증액과 정기 수집 활성화는 보류한다.

- 글쓰기 입력을 900ms 동안 멈추면 서버의 본인 전용 working copy를 저장한다. 새 글은 계정/조직/모드별 한 개, 저장된 글은 작성물별 한 개다. 여러 창의 수정은 임시 저장 변경 번호로 충돌을 감지하고 중단한다. 저장된 본문의 버전도 재확인한다.
- 최초 복원은 명시적으로 선택한다. 30일이 지난 임시 payload는 복원하지 않으며, 변경 번호는 유지해 오래된 창이 다시 덮어쓰지 못하게 한다. 물리적 데이터 삭제 주기는 별도 운영 과제다.
- 네트워크 실패/충돌을 성공으로 표시하지 않는다. 아직 서버에 반영되지 않은 입력이 있으면 새로고침과 화면 이탈을 안내한다. 브라우저 강제 종료나 저장 완료 전 장치 종료까지 보장하지 않는다.
- 명시적 작성 이력 저장은 불변 버전을 남기고 해당 창이 가진 임시 저장만 비운다. 사라진 사전 항목 때문에 복원한 글을 저장하지 못하면 복원 항목을 제외하고 본문만 저장할 수 있다.
- 개인 사전의 뜻/개인 메모/분류/즐겨찾기/사용법/중한 예문 최대10개를 수정한다. 출처와 원래 주의사항은 변경하지 않는다. 개인 편집은 공용 사전에 전파하지 않으며 반복 저장은 개인 수정을 보존한다.
- 공개 사전의 기존 학습 가이드는 알려진 표현에만 사용법·창작 예문으로 보존한다. AI 표현 해석의 usageKo도 저장한다. 확인되지 않은 예문을 AI로 새로 만들거나 실제 게시물 인용으로 표현하지 않는다.
- 개인 예문과 사용법은 표현 연습 화면에서 재사용한다. private 정보는 본인·조직·mode로 격리한다. RLS에 관리자 예외는 없다.
