# 0034 — 범용 키워드 확장과 비공개 기획 연결

주제별 편집 예시 외에 query_expansion 작업의 expand 유형으로 OpenAI가 핵심·연관·롱테일 후보를 만든다. 기존 verified 단가, 견적, 동의, 예약, 월 한도와 unknown_outcome 중복 방지 흐름을 사용한다. 번역/표현 해석 응답과 구별된 keywords 계약으로 검증한다.

입력은 검색 의도, 현재 조직/모드의 공개 사전 설명과 접근 가능한 게시물 발췌다. 길이를 제한하고 URL·민감 문자열을 제거한다. AI는 뜻과 추천 이유만 제안한다. 관찰 횟수·사전 출처·게시물 근거는 서버에서 재구성하며 추천 자체는 실사용 증거가 아니다.

선택 최대 8개를 기획에 가져올 때 후보를 서버에서 다시 계산하고, AI job 소유자/조직/모드/성공 여부를 검사한다. 사용자 입력으로 근거를 덧붙일 수 없다. 저장 요청은 소유자별 advisory lock과 requestId로 중복 방지한다. 초안 태그, 사용자가 입력한 사실과 촬영 장면, 별도 keywordSource 스냅샷을 저장한다. 사실은 미입력 상태를 허용하며 광고 여부 기본은 unknown이다.

기존 AI 기획 입력에 현재 선택 태그/뜻을 전달한다. 소재와 제품 효능·경험을 구분하는 프롬프트를 사용하고, 기존 사실 입력·촬영 가능 장면 요구 및 제안 적용 절차를 유지한다. 자동 게시나 키워드별 자동 유료 검색은 없다.
