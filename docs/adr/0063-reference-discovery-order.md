# 0063 — 반응과 한국 관련 키워드 기반 추천 정렬

2026-11-20 사용자 요청에 따라 탐색의 기본값을 추천순으로 변경한다.

- 최신 저장 스냅샷의 좋아요·저장·댓글에 각각 ln(1 + 수치)를 적용하고 합산한다. exact가 없으면 lowerBound를 사용한다. 누락·음수는 점수 0으로 처리한다.
- 제목·본문 발췌·태그에 한국/서울 등 관련 키워드가 있고 반응 점수가 양수이면 2점을 더한다. 키워드만 있고 반응이 없는 자료를 우선 추천하지 않는다.
- 동점은 기존 게시일·내부 ID 순서로 안정적으로 정렬한다. 기존 원문 확인/공유주소 조건을 페이지 분할 전에 적용한다.
- 좋아요순·저장순·최신순은 유지한다. 기존 URL에 명시된 정렬도 유지한다.
- 플랫폼 전체 인기 순위, 조회 대비 반응률, 한국 촬영 여부 또는 콘텐츠 품질 보장이 아니다. 수집 때 저장한 수치이며 실시간 갱신하지 않는다.
- 수집 조건·예산·실행 스위치는 변경하지 않는다. 원문 확인 미완료 자료는 공개하지 않는다.
