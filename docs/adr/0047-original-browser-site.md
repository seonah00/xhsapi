# 0047 원문 브라우저 목적지

2026-10-21. 사용자 승인: 로그인에서 멈춘 두 링크를 무증액·신규 유료 수집 없이 개선.

동일 게시물의 기존 공유 주소가 중국 사이트에서는 로그인 페이지에 머물렀다. 웹 explore 경로만으로는 해결되지 않았다. 공유 토큰·출처를 유지한 rednote.com/discovery/item 경로에서 두 게시물 제목·본문이 일치하고 영상 실제 재생을 확인했다. 공식 UI로 공개 원문을 열었으며 로그인 쿠키 공유나 접근 우회는 하지 않았다.

인증·조직·모드 검사 뒤 original 라우트는 기본 rednote 목적지를 사용한다. site=xiaohongshu로 기존 사이트를 명시적으로 선택할 수 있다. 허용 사이트 둘 이외에는 400. 목적지 생성은 검증된 동일 게시물 공유 주소만 입력받고 토큰이 없거나 검색/계정/타 호스트 주소이면 거절한다. 원래 보관 주소·canonical·수명은 변경하지 않는다. 전체 서명 주소는 HTML·문서·로그에 노출하지 않으며 no-store/no-referrer를 유지한다.

두 표본 성공은 전체 게시물/향후 로그인 정책을 보장하지 않는다. 사용자·브라우저별 로그인, 삭제, 주소 만료는 여전히 별개다. 자동 실패 감지는 타 도메인 접근 제한 때문에 하지 않으며 학생이 보조 링크를 선택한다. 유료 호출/예산/정기 수집 변경 없음.
