# 0022 공용사전에서 비공개 기획으로 가져오기

2026-10-08 사용자 요청: 공용사전 초안을 기획실로 가져오되 기존 REDi와 기능 중복을 피한다.

REDi 운영 UI 확인: Studio에 썸네일 비주얼, 제목 A/B, 해시태그 추천, 원고/대본, 영상 분석, 포토피드 기능이 있고 Planner에 성장 로드맵, 아이디어, 트렌드 캘린더가 있다. 기능 메뉴 확인이며 해당 생성기의 실행 품질을 검증한 것은 아니다.

이 앱은 검토된 사전의 표현 선택·뜻 이해·내 소재 적용·촬영 실행 작업지에 집중한다. 범용 생성기·댓글 도우미·일정 캘린더를 추가하지 않는다. 기존 기능을 임의 삭제하지 않는다.

- 선택 항목만으로도 비공개 기획 생성 가능. 생성 결과가 있으면 제목 후보 선택, 표지 문구 직접 입력, 본문/한국어/태그를 저장한다.
- 입력 변경 후 이전 AI 결과와 새 선택을 섞어 가져오지 못한다.
- 계정이 없으면 새 창 설정 후 목록 갱신으로 현재 결과를 유지한다.
- 명시적 저장 때만 기존 plans에 보관한다. usage 테이블에 본문은 저장하지 않는다.
- 사전의 공개 항목을 서버에서 재조회해 뜻·주의점만 복사한다. 원자료는 가져오지 않는다. retired/다른 조직/다른 데이터모드 항목은 거부한다.
- 추가 AI 호출 없음. 저장한 본문은 사용자 초안이며 공급자 진위를 증명하지 않는다. 실제 경험·촬영 장면은 직접 확인하도록 비워 둔다.
- 사용자/조직별 가져오기 키와 트랜잭션 잠금으로 중복 저장 방지. 삭제된 기획은 같은 키로 복제하지 않는다.
- 사전 작업 메모는 draft_json.dictionarySource로 보관하고 일반 자동저장/제안적용에서도 유지한다. 편집 버전의 콘텐츠/사실만 변경한다.
- 기존 장면별 촬영표와 제목·표지 편집을 재사용한다. 새 스키마 마이그레이션 없음.

검증: 선택·저장·다시 열기 E2E, 데이터·권한·중복·자동저장 통합 테스트. 유료 AI 호출 없이 검증한다.
