# ADR 0032 — 중국어 검색어 확인과 검색 표본 표현 분석

한국어 검색에서 중국어 검색어를 확인·수정한 뒤 기존 자동 검색 경로로 전달한다. 사전 기반 조합은 의미가 일부만 변환되면 실행 후보를 만들지 않는다. 임의 문장의 AI 번역은 이번 구현에 포함하지 않으며, 모르는 단어는 명시하고 직접 중국어 입력을 지원한다. 별도 유료 호출이나 예산 우회는 추가하지 않는다.

현재 페이지(최대 50건)의 실제 제목·본문 일부·공급자 태그에서만 해시태그와 표현을 집계한다. 플랫폼 게시물 ID 중복을 제거하고 태그 반복은 게시물당 한 번 센다. 작성자 식별자가 없는 경우 작성자 수에 넣지 않는다. 원문 예시, 관찰 기간, 분모, mock 여부를 표시한다. 전체 플랫폼 인기·작성자 국적·트렌드 상승을 추론하지 않는다.

공개된 조직별 공용사전은 뜻·주의사항 및 표현 탐지에만 사용한다. 사전의 관찰 수는 이 검색의 집계에 합산하지 않는다. 영문 약어 모양은 뜻 미확인의 후보이며 브랜드나 일반 단어일 수 있다. 사전 밖 중국어 신조어 전체를 탐지한다고 주장하지 않는다. URL을 표현 탐지·문맥에서 제외한다. 근거 링크는 인증된 내부 게시물 상세 화면으로 연결한다.

학생 화면에 별도 과금 승인은 추가하지 않는다. 기존 조직 자동 검색 정책·예산·캐시·월 한도가 그대로 적용된다. 정책이 꺼졌으면 저장 자료 검색으로 돌아간다.

## 후속: AI 자유문장 번역·문맥 해석

기존 query_expansion 작업 종류를 실제 구현하고 AI01(OpenAI, LLM_MODEL)의 검증 단가·예약 원장·월 한도·동의·재실행 방지를 재사용한다. 검색 문장은 최대 1,000자이고, 출력은 중국어 검색어 1~3개다. 사용자가 선택한 뒤에만 기존 수집 경로로 넘어간다.

표현 해석은 접근 가능한 같은 조직·데이터 모드의 게시물 ID만 받는다. 서버가 제목·본문·태그를 읽고 URL/민감 문자열 제거 후 11KB 이내의 발췌 표본을 구성한다. 모델에는 내부 ID 대신 alias를 보낸다. 출력의 표현·인용문·alias를 입력과 정확히 대조하고 중복·허위 근거는 거부한다. 표본 건수는 실제 전송한 수, 빈도는 모델의 주장 대신 서버 계산값이다. 임의 중국어 표현의 뜻은 AI 해석이며 확신도·주의사항과 함께 표시한다.

학생 확인 화면은 외부 AI 동의와 이용 한도를 설명하고, 금액은 관리자에게만 표시한다. 새로운 조직 예산·자동 과금 정책은 만들지 않는다. 전송 후 실패 또는 불확실한 결과는 unknown_outcome으로 남겨 중복 호출하지 않는다. 결과는 기존 소유자 전용 app_jobs에 보관하고 렌더링 시 게시물 접근·만료를 다시 확인한다. mock은 명확히 표시한 고정 번역/빈 해석을 반환하며 실제 AI를 부르지 않는다.
