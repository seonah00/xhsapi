# ADR 0020: 공유 링크·운영자 부담 검색·AI 레퍼런스 분석

2026-10-07 사용자 요청으로 세 기능을 순서대로 구현한다. 원문 404는 링크 구조만으로 해결을 보장할 수 없다.

## 공유 링크

공급자가 반환한 동일 노트의 https 공유 URL/xsec_token만 수용한다. canonical URL은 계속 토큰 없는 식별자다. 공유 링크는 서비스 전용 note_access_links에 24시간 보관하고 만료 시 삭제한다. 목록에는 보유 여부만 노출한다. 로그인·조직·모드 확인 후 원문 이동 경로에서만 브라우저를 해당 링크로 보낸다. API 인증 키와 로그인 토큰은 여전히 서버 secret이다. 공개 게시물 공유 정보는 이 이동 목적에 한해 허용하며 로그·AI 입력·provenance에는 넣지 않는다. 다른 게시물 ID·프로필·다른 호스트는 거부한다. 서명 없는 재수집이 유효한 기존 링크를 지우지 않는다. 저장된 토큰 없는 자료는 자동 복구되지 않으며 다음 승인된 수집/보완에서 갱신한다. 단축 URL은 노트 ID를 검증할 수 없어 자동 채택하지 않는다.

## 학생 자동 검색

기본 꺼짐. 관리자가 공급자 화면에서 종료일(최대 31일), 회당 CNY 상한, 일일 조직/학생 검색 수, 결과 재사용 시간을 승인한다. live 환경에는 AUTO_REFRESH_ENABLED가 추가로 필요하다. 기존 통화별 월간 예산을 늘리지 않는다. 서버는 승인 관리자 명의로 기존 검증 단가·견적·예약 절차를 실행한다. 학생에게 비용 확인 UI를 노출하지 않으며 외부 검색어 전송 안내와 상태만 표시한다. 동일 조직/모드/검색어는 캐시와 진행 중 작업을 공유한다. 조직 단위 트랜잭션 잠금으로 동시 요청 중복·쿼터 경쟁을 막는다. 요청자는 자신의 상태만 조회한다. 작업마다 관리자 재직·승인 기간·스위치를 재검사한다. unknown_outcome은 자동 재실행하지 않는다. 50건 목표/5페이지 상한이며 결과 수를 보장하지 않는다. 표지 추가 호출은 포함하지 않는다.

## 실제 레퍼런스 분석

OpenAI Chat Completions의 구조화 출력 사용. 제목·본문 발췌·태그·사용자 텍스트·메모만 전송하고 개인정보 패턴을 마스킹한다. 영상/이미지/음성 문안·URL·공유 토큰은 입력하지 않는다. 입력 JSON 12KB 제한, 출력 2,000 토큰 제한. 모델과 검증 단가(입력 최대 20,000 토큰 + 출력 2,000 토큰을 커버하는 USD/run 상한), USD 예산, LIVE_LLM_CALLS_ENABLED, 조직 스위치, 요청별 전송 동의가 있어야 실행한다. 모델은 단가 버전에 묶인다. 모델/가격은 이 변경에서 임의 등록하지 않는다.

관찰/추론/제안 구분과 근거 ID를 검증한다. 영상 전체를 분석했다고 표시하지 않는다. 외부 전송 전에 작업 마커를 커밋하고, 응답 유실·거부·잘못된 결과는 비용 확인 대상으로 보존하며 재시도하지 않는다. 기획 생성·성과 해석의 live AI는 이 범위에 포함하지 않는다.

공식 API 계약: https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create

검증은 합성 응답과 로컬/CI DB·브라우저를 사용한다. 이번 구현 과정에 과금 공급자 호출은 하지 않는다. 실제 기능 활성화는 키·모델·확인된 단가·현재 예산과 관리자 설정이 갖춰진 뒤 한다.
