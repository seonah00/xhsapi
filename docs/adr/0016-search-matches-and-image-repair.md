# 0016 — 검색 결과 연결과 이미지 업데이트

- 공급자 검색 결과의 검색어-게시물 관계를 note_search_matches에 보존한다. 제목/태그의 완전 일치가 없어도 원래 검색 결과에 표시하며 다른 검색으로 재수집해도 관계를 유지한다.
- 조직 멤버 읽기 RLS, 복합 외래키, 기존 날짜/주제/형식 필터와 50건 페이지를 유지한다. fallback 결과는 관계에 추가하지 않는다.
- 마이그레이션 19는 기존 수집 작업의 정확한 noteIds로 관계를 복구한다.
- 표지 URL 유무뿐 아니라 브라우저 onError를 이미지 업데이트 대상에 포함한다. 다른 URL로 교체되면 이전 실패 상태는 적용하지 않는다.
- 수강생 버튼은 이미지 업데이트/정보 업데이트로 표시한다. 저장 검색과 새 게시물 50건 조회를 구분하고 진행 상황을 상단에 표시한다.
- 이미지 실패는 자동 유료 호출을 시작하지 않는다. 기존 견적·비용 동의·50건 상한을 유지한다.
- 공식 Actor 메타데이터(2026-10-07): 시작 $0.05 + 결과 $0.00999 + dataset $0.00001 = 최대 $0.06/1건 실행(기본 512MB, 다운로드 없음). 운영 단가 및 하루 USD 3 한도를 사용자 승인에 따라 등록했다.
