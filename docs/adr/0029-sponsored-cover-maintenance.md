# ADR 0029 — 탐색 표지의 운영자 부담 자동 갱신

사용자는 남은 자동 검색·표지 갱신·성과 AI 검증 진행을 요청했다. 탐색에서 실제로 실패했거나 주소가 없는 표지를 관리자 정책 범위 안에서 Apify로 갱신한다. 학생에게 비용 확인 버튼을 추가하지 않는다.

- 조직 정책에 관리자, 최대 31일 종료일, 월간 조회 건수, 요청별 USD 상한을 저장한다. 기본 꺼짐. 기존 환경·단가·견적·동의·예산 예약 경로를 재사용한다.
- 화면 방문당 한 번, 최대 5건. 조직별 잠금으로 중복 예약과 월 한도 경쟁을 막는다. 동일 게시물 24시간 재요청 금지, 결과 불명은 기간과 관계없이 격리한다. 결과 없음도 조회 건수에 포함한다.
- 유효 조직 자료만 조회한다. 후원 작업 진행 상태만 같은 조직 활성 멤버에게 공개하고 관리자 개인 작업·견적·입력은 공개하지 않는다. 워커는 각 항목 전 정책 만료·중지·관리자 자격을 재검증한다.
- 이미지 자체나 영상을 서버에 다운로드하지 않는다. 공급자 반환 표지·공유 링크의 기존 TTL을 유지하며 열람 수요에 따라 갱신한다. 외부 CDN 차단/삭제를 해결한다고 보장하지 않는다.
- 자동 검색 정책이 켜지면 관리자의 탐색 검색도 동일 경로로 확인할 수 있다. 별도 수동 수집 버튼은 유지한다.

검증: 조직 격리, 동시 중복, 월간 건수, 24시간/불확정 격리, 실행 직전 중지의 DB 테스트와 학생 화면 이미지 교체·비용 UI 부재의 E2E를 추가한다. 운영 검증 결과는 HANDOFF에 기록한다.
