# 0025 내 사전 사용 이력

사용자의 다음 개발 요청에 따라 사전 가져오기 이력을 구현한다. 제목·날짜·선택 항목만 목록에 표시하며 메모·본문은 가져오지 않는다. 실제 사용 여부를 추정하지 않고 기획에 가져온 기록이라는 의미를 명시한다.

기존 plans.dictionarySource 자료를 조회해 과거 기록도 포함한다. org_id와 owner_user_id 조건을 RLS와 함께 적용하며 deleted_at이 있는 기획은 제외한다. 공개 사전의 현재 상태와 무관하게 저장 당시 선택은 남지만 사전으로 가는 링크는 현재 공개 검색만 수행한다.

검색은 표현·태그의 대소문자 무시 부분 일치이며 %/_도 일반 문자로 처리한다. 입력 120자, 페이지 20건. 공개 이력·추가 사용자 추적 테이블·외부 공급자 호출은 없다.

검증: 본인 이력, 다른 사용자·조직 제외, 삭제 제외, 페이지 보정, 리터럴 검색, UI 검색 후 기획 다시 열기.
