# 0042 개인 사전과 독립 글쓰기

2026-10-20. 사용자가 표현 해석 수정 → 내 사전 → 바로 글쓰기·작성 이력을 요청했다. 예산 증액과 정기 수집 활성화는 보류한다.

- 표현 해석은 엄격한 응답 외형을 유지하면서 각 후보를 개별 검증한다. 형식·원문 근거 검증 실패 후보는 제외하고 제외 수를 표시한다. 전부 실패하면 실패 처리한다. 공급자 재시도나 추가 호출은 없다. 과거 실패의 정확한 필드 원인은 기록이 없어 확정하지 않는다.
- 공용사전, 실제 검색에서 관찰된 태그, 본인 AI 해석 결과를 서버에서 다시 확인해 개인 항목으로 저장한다. 직접 등록은 실사용 미검증으로 구분한다. 원문 인용·공유 토큰은 복제하지 않는다.
- 개인 항목과 작성물은 조직·사용자·데이터 모드로 격리한다. 관리자도 다른 사용자의 비공개 항목을 읽지 못한다. 사전 삭제는 숨김이며 작성물에 저장한 단어·뜻은 보존한다.
- 기존 Gemini 작성의 서명·동의·예산 제어를 재사용하고 서명에 데이터 모드를 추가한다. 직접 편집·저장에는 제공자를 호출하지 않는다. AI 결과 적용은 명시적 버튼으로 한다.
- 제목·표지 문구·본문·한국어 확인본·태그를 저장하고 저장마다 불변 버전을 남긴다. 예상 버전과 행 잠금으로 동시 수정의 덮어쓰기를 막는다. 자동 게시하지 않는다.
- 개인 사전 목록은 최신 200개, 작성 목록은 최신 100개, 이전 버전 표시는 최신 50개다. 과거 버전 삭제·자동 복원은 이번 범위에 포함하지 않는다.
