# 0023 촬영 실행 작업지

2026-10-09 사용자 요청: REDi와 역할을 나눈 웹서비스 기능 보완.

기존 촬영표를 확장해 장면별 구도, 자막, 준비물, 촬영 완료 체크와 순서를 관리한다. 범용 아이디어 생성기를 추가하지 않는다. 선택 필드로 저장해 기존 버전과 AI 제안을 유지한다. 수동 입력과 기존 자동 저장/버전/권한 경계를 사용하며 공급자 호출은 없다.

최종본 복사, Markdown/JSON 내보내기 및 제출 검토 화면에 같은 내용을 표시한다. 장면 자막은 점검 입력에 합쳐 자막 변경 시 재점검 필요 상태를 유지한다. 자막 최대치는 공통 5,000자와 30장면 각각 500자 및 줄바꿈을 수용한다. 준비 상태 변경만으로 문구 점검을 무효화하지 않는다.

검증: 옛 데이터 호환, 제한 검증, 점검 해시, 장면 이동 후 메타데이터 보존, 자동 저장·재열기·버전 저장·최종본 표시.
