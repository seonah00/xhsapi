# 0037 — 사전·탐색 중심 화면과 Apify 원문 재검색

2026-10-13 사용자 요청: 레퍼런스·참고 계정·기획실·점검·제출 탭 제거, 사전 표현 활용 강화, 표지에서 원문 연결 상태와 링크 확인.

- 주 메뉴와 홈, 탐색 카드, 키워드 선택, 사전 작성 화면에서 해당 기능 진입을 제거한다. 기존 비공개 자료와 과거 URL/API는 삭제하지 않는다. 기존 API 회귀 검증을 유지한다.
- 사전 검색 시 권한 있는 저장 게시물 최대 50건의 실제 태그/표현/인용 근거를 기존 SearchLanguage로 보여준다. 별도 게시물 검색 버튼은 기존 승인된 검색 경로를 사용한다. 공개 사전의 뜻과 실제 사용 빈도, AI 해석은 구별한다. 작성자 국적이나 플랫폼 전체 유행을 추정하지 않는다.
- 선택 표현의 뉘앙스·주의·학습 예문과 자유 문장 연습을 기획 가져오기에서 독립시킨다. AI 제목·본문·태그 및 연습 문장을 복사해 외부 서비스에서 사용한다.
- 표지 클릭은 내부 상세를 연다. 기본 주소를 표시하고 유효 공유 링크가 있을 때 주소/버튼으로 인증된 내부 원문 리디렉션을 제공한다. 기본 주소 복사는 토큰 없는 주소임을 표시한다. 공유 토큰은 HTML/AI에 넣지 않는다.
- 원문이 없으면 사용자가 누르는 재검색 액션이 서버에서 조직/모드/만료/ID를 검사한 뒤 저장 제목으로 Apify 자동 검색을 요청한다. 자동 검색 정책의 provider가 apify여야 하며 기존 상한·예약·캐시·동시 중복 방지·unknown_outcome 재전송 금지를 재사용한다. 동일 플랫폼 ID가 다시 발견돼야 원문 버튼이 활성화된다. 다른 검색 결과를 복구로 간주하지 않는다.
- 유효 링크가 있으면 재검색하지 않는다. 24시간 TTL, 로그인 제한, 삭제된 원문에 대한 우회는 변경하지 않는다. 일괄 재수집/추가 과금/예산 증액은 실행하지 않는다.
