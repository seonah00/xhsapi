# ADR 0007 — live 실행 경로 (M5 준비, 실호출 없음)

날짜: 2026-10-05 · 상태: 채택

## 맥락

키를 넣은 뒤 첫 실측에서 비용 누수나 중복 요청이 생기지 않도록, 실제 호출 경로를 키와 네트워크 없이 먼저 만들고 검증한다. RedFox 문서 중 요청·응답 형식을 받은 것은 음성 문안 추출(RF13 제출, RF14 결과)뿐이다. 검색(RF01) 등은 응답 형식을 확인하지 못했다.

## 결정

1. **단가는 운영자가 서버에서 등록.** 가격 버전(`provider_price_versions`)은 조직이 아닌 공급자에 대한 전역 사실이다. 그래서 조직 관리자 화면이 아니라 `pnpm price register`(서버 권한)로 등록하고, 근거·확인자·적용 시각을 남긴다. 등록하면 해당 엔드포인트가 `price_status = verified`가 되고, `pnpm price unverify`로 다시 막을 수 있다. 이력은 유지한다.
2. **live 견적.** 견적 단계에서 실제 게이트를 서버 권한으로 미리 평가한다(학생은 RLS상 허가·예산을 읽을 수 없다). 다음 중 하나라도 해당하면 견적을 거부하고 이유를 한국어로 보여 준다: 단가 미확인, 허가·스위치 미충족, 예산 0, 통화 불일치. 최대 금액은 SQL numeric으로 `단가 × 최대 단위`를 합산한다. 음성 문안 추출은 RF13 1회와 RF14 결과 조회 최대 20회를 함께 예약한다. AI·OCR 등 제공자가 정해지지 않은 작업은 live 견적을 거부한다.
3. **학생 동의.** live 견적 확인 화면에 필수 동의 체크박스를 둔다. 확인할 때 `consent_records`(`transcript` 또는 `external_provider_query`)에 기록하고, 워커는 실행 직전 게이트에서 동의가 있는지 다시 확인한다.
4. **워커.** live 모드에서는 `REDFOX_API_KEY`가 없으면 시작하지 않는다. live 작업마다 저장된 상태로 게이트를 구성하고 어댑터를 만든다. 게이트 구성 요소는 허가·DB 단가 상태·조직 스위치·동의·해당 작업의 원장 예약·견적 소비 여부다. 어댑터는 호출 직전에 게이트를 다시 평가한다. 외부 연결 차단 가드는 live에서도 켜고, DB와 `redfox.hk`만 허용한다. 웹 서버는 공급자를 직접 부르지 않으므로 모든 모드에서 DB 외 외부 연결을 막는다.
5. **정산 원칙.**
   - 성공하면 예약액 전액을 정산한다. 공급자 과금 보고가 생기기 전까지 보수적으로 처리하는 것이다.
   - 요청을 보내기 전에 막히면 예약을 반환한다(`released`). 해당 경우: 게이트 차단, 형식 미확인, 멤버십·스위치 문제, live 미구성.
   - 보낸 뒤 결과를 모르면 `unknown_outcome`으로 둔다. 예약은 유지하고 관리자가 정산한다. 제출(RF13)은 다시 보내지 않는다.
   - 결과 조회(RF14)는 일시 오류면 백오프로 재시도하고, 형식 위반이면 실패 처리한다. 예약한 횟수를 넘겨 조회하지 않는다.
6. **형식 미확인 엔드포인트.** RF01·RF09 같은 엔드포인트는 필드를 추측하지 않는다. 요청 전에 `ProviderNotReadyError`로 거부하므로 비용이 생기지 않고 예약도 반환된다. 응답 형식은 문서를 받거나, 승인된 소량 실측에서 민감정보를 지운 응답을 확보한 뒤 매핑한다.

## 결과

- 코드: `packages/core/src/live.ts`, `quotes.ts`/`jobs.ts` 수정, `apps/worker` live 모드, `scripts/price.ts`.
- 테스트: 가짜 RedFox(fetch 주입, 네트워크 없음)로 DB 테스트 6개.
  - 정상 흐름: 견적 → 동의 → 예약 → 서버 키로 호출 → 정산 → 결과 조회.
  - 실행 직전 허가 철회: 요청 0건, 예약 반환.
  - 응답 유실: `unknown_outcome`, 재전송 없음.
  - live 미구성 워커: 거부하고 예약 반환.
  - 단가·예산·제공자 미정 작업: 견적 거부.
  - RF14 조회 횟수 상한.
- 단가 등록 입력 검증 단위 테스트를 추가했다.
