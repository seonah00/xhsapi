# ADR 0059: 탐색과 모음집 중심 홈

- 날짜: 2026-11-02
- 상태: 승인된 UI 개선, 전체 검증 후 배포

## 결정
동일한 네 카드 대신 게시물 검색과 여섯 주제 바로가기를 상단에 배치하고 해시태그·표현 카드, 내 모음 바로가기를 구분한다. 기존 서버 검색 액션을 사용해 한국어 검색어 확인과 저장자료 조회 정책을 유지한다. 새 유료 호출이나 DB 변경은 없다.

로그인 설명의 퇴역 기획 문구를 제거하고, 사전의 게시물 조회 버튼은 이동 결과가 명확한 문구로 바꾼다. 기존 기능 삭제나 예산 갱신은 이번 디자인 배포에 포함하지 않는다.

## 검증
홈→중국어 검색→결과, 한국어→검색어 확인, 주제 필터, 태그·표현·내 모음 이동을 desktop/mobile E2E로 검사한다. 접근성·가로넘침·pageerror 및 작업 수 불변도 확인한다. 전체 DB/E2E 검증은 가짜 외부 공급자를 사용한다.
