# ADR 0035: AI 출력 오류 진단과 기획 범위 검증

## 배경

운영 검증에서 언어 확장은 Zod 오류의 위치를 알 수 없었고, 기획 제안은 입력에 없는 재질·휴대성을 추가했다. 표지 카피 대신 촬영 설명과 입력 밖 장면도 생성됐다.

## 결정

- 언어 응답 스키마 오류는 허용된 경로 이름, 배열 위치의 고정 표기(item), Zod 오류 종류만 남긴다. 원문, 값, 임의 속성명, 오류 메시지는 기록하지 않는다.
- 번역·표현의 길이와 배열 수 제한을 모델 응답 schema에도 전달한다. 과거 실패 원인은 추정하지 않는다.
- 기획 표지는 2~30자 중국어 카피로 제한한다. 한국어 및 흔한 촬영 지시어를 거부한다.
- 촬영 scene은 입력 shootableScenes의 enum으로 요청하고 서버에서도 일치를 검증한다. 메모는 해당 장면의 촬영 제안이다.
- 재질·휴대성·방수·작은 크기는 확인된 사실에 해당 속성이 없으면 보수적으로 거부한다. 부정/미확인 사실은 근거에서 제외한다. 단순 패턴 검사는 동의어 및 복잡한 문맥을 모두 판별하지 못하며 일부 정상 응답도 거부할 수 있다.
- 모든 의미적 정확성을 보장하는 장치가 아니다. 기존 사람 검토, 제안 별도 저장 및 명시적 적용을 유지한다.
- 응답 검증 실패는 원문을 제안으로 저장하지 않고 unknown_outcome을 유지한다. 실제 호출 비용이 발생했을 수 있으므로 예약을 무료 정산하거나 자동 재시도하지 않는다.

## 검증

가짜 모델 응답으로 한국어 표지, 미확인 재질/휴대성/방수, 입력 밖 장면 및 비공개 오류 문자열 노출을 회귀 검증한다. 실제 모델 성공은 별도 운영 검증으로만 판단한다.
