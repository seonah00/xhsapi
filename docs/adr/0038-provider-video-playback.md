# 0038 — Provider-supplied video playback

User requested viewing videos without QR or broken platform links. Preserve only validated transcoded H.264 stream URLs from selected-note Apify responses in the existing enrichment TTL/RLS boundary. No media download, proxy, rehosting, watermark manipulation or paid retry. Do not include URLs in discovery, canonical URLs, provenance or AI inputs. Browser makes the media request only after explicit play. Permit HTTPS sns-v<number>.rednotecdn.com /stream/*.mp4 only; HTTP provider URLs upgrade to HTTPS without fallback. Browser playback remains conditional on CDN availability and codec support. Missing/failed/expired URLs must not be presented as successful playback. Existing enrichments require a supplied response or future explicitly authorized enrichment; do not mass-refetch.
