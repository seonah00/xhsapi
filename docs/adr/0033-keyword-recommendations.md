# 0033 — 사전·관찰 근거와 검색 후보 분리

공개 공용사전 정의와 현재 탐색 표본의 태그를 합쳐 핵심·연관·롱테일 검색 후보를 제공한다. 사전의 과거 관찰 수는 실시간 사용 횟수로 간주하지 않는다. 빈도는 기존 중복 제거 표본 분석만 사용한다.

첫 버전의 자동 확장은 선크림·여행·패션의 편집된 검색 예시이며 AI 추천 또는 실사용 확인으로 표시하지 않는다. 다른 주제는 중국어 대상·상황을 직접 조합할 수 있다. 관련 태그는 현재 표본의 동시 출현이며 의미적 연관성 보장은 아니다.

후보 선택은 추가 수집을 실행하지 않는다. 개별 검색 버튼만 기존 자동 검색 예산·동의·횟수 제한을 거친다. 선택 태그 복사와 기존 사전 작성 흐름을 제공한다. 여러 출처를 보존한 기획실 일괄 가져오기 및 임의 주제 자동 의미 확장은 후속 작업이다.
