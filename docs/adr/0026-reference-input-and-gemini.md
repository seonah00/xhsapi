# ADR 0026: 레퍼런스 입력 준비와 Gemini 선택

2026-10-12 · 채택

## 문제

운영 레퍼런스가 링크만 보유하고 제목·본문·태그가 비어 있다. 분석 요청은 자료 검사보다 OpenAI 가격 오류를 먼저 표시했다. 등록된 Gemini 키는 사전 문안 전용이며 레퍼런스 분석에 연결되지 않았다. 이미지 CDN 403은 별도의 문제다.

## 결정

- 제목·본문·태그·메모의 유효 텍스트를 견적 전에 확인한다. 직접 입력 본문 편집을 제공한다. 서버에서도 소유권·삭제·만료·크기를 확인한다.
- 기존 상세 분석의 8개 섹션·문구 인용·근거 검증을 Gemini에도 적용한다. API 요청은 텍스트 한정, 6,000 출력 토큰, 불완전 결과 거절, 자동 재시도 없음이다.
- REFERENCE_AI_PROVIDER 기본은 openai. Gemini는 모델을 명시하고 전용 gemini/AI01 검증 단가를 사용한다. 예약 시 제공자와 모델을 고정하고 worker에서 재검사한다. 기존 기획/회고는 OpenAI 유지다.
- 관리자 본인 링크만 AP01 기존 예약 흐름으로 조회한다. 학생에게 수집 비용 화면을 노출하지 않는다. URL은 XHS 노트/짧은 공유 경로만 허용하며 계정 경로·다른 호스트·인증/쿼리/포트는 거절한다. 단축 URL은 Actor가 처리하며 앱이 직접 따라가지 않는다.
- 공급자 결과는 기존 notes/enrichment 저장과 TTL을 사용하며 메모/직접 입력 내용은 Apify에 전송하지 않는다. 저장된 링크는 조회와 별도로 그대로 유지한다.

## 운영 경계

이 변경만으로 Gemini 실행 또는 새 비용 예산을 활성화하지 않는다. 공용사전 모델의 단가를 자동 적용하지 않는다. 운영 모델과 요금 검증, 예산 설정, 소량 실측은 별도다. 원문 접근 실패는 직접 텍스트 입력으로 대응하며 차단을 우회하지 않는다.
