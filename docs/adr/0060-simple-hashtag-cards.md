# ADR 0060: 해시태그 뜻과 사용법 중심 카드

- 날짜: 2026-11-02
- 상태: 구현·전체 검증·운영 배포 완료 (47ad42c)

학생은 태그의 뜻과 사용 상황을 우선 확인한다. 공용사전의 기존 usage를 전달하고, 없으면 한국어 뜻 기반의 일반 안내를 표시한다. 뜻 자체가 없으면 임의 번역하지 않는다. 중요한 주의사항은 계속 표시한다.

통계·기간·근거 게시물은 접힌 상세 영역에 보존하고, 정렬 기준과 검색어 조합도 기본적으로 접는다. 실사용 미확인 후보의 복사/저장은 허용하지 않으며 기존 수집 게이트는 변경하지 않는다.

단위 테스트에서 usage 전달, E2E에서 통계 기본 숨김과 상세 펼치기를 검증한다.
