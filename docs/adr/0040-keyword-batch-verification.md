# 0040 후보 일괄 검증과 수집 표본의 게시 기간 비교

2026-10-20

- 사용자가 AI 확장 실검증, 후보 자동 검증, 최근 사용 증가 추적을 요청했다.
- 후보 화면에서 한 번의 실행으로 최대 3개를 접수한다. 서버가 사전/AI 출처와 소유권을 다시 조회해 후보를 검증한다. 임의 입력·이미 확인된 태그는 이 경로에서 받지 않는다.
- 기존 requestAutoSearch 정책/견적/예약/학생 월한도/조직 한도/24시간 캐시를 재사용한다. 한 트랜잭션에서 모든 후보를 예약하므로 중간 한도 초과 시 일부만 과금 작업으로 남지 않는다. unknown_outcome은 기존 작업을 재사용하고 재발송하지 않는다.
- 결과 화면은 본인 search_requests ID 최대 3개로 조회한다. 서비스 접근 후에도 조직/소유자/모드/작업 종류를 확인하고 실제 노트는 사용자 RLS/모드/만료를 다시 확인한다. 성공 응답의 정확한 태그가 있어야 복사 가능하다.
- 최근 사용 변화는 동일 수집 표본 안의 게시일 기준 최근 7일과 이전 7일의 태그 사용 비중 차이(%p)다. 한국 시간 오늘은 제외한다. 각 기간 전체 10건·해당 태그 3건 이상을 확보해야 표시한다. 날짜 없는 자료/미래 게시물/플랫폼 중복은 제외한다. 검색량/플랫폼 전체 유행/인과 효과가 아니다.
- 별도 정기 유료 재수집이나 역사적 관찰 스냅샷 저장은 추가하지 않는다. 기존 승인 검색이 갱신되면 그 표본으로 다시 비교한다. 장기간 시계열 추적은 동일 수집 조건의 스냅샷 저장과 별도 갱신 정책이 필요하다.
- 사용자는 실제 검증을 위해 월 USD 한도 1달러 추가(55.78→56.78)를 승인했다. AI 1회 최대0.0176, 후보검색 최대3회×0.325. 과거 불명 예약0.0704는 유지한다.
