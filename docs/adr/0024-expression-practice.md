# 0024 표현 활용 가이드와 기획 연결

2026-10-12 다음 개발 요청에 따라 표현 활용 가이드를 우선 구현한다. 사전 뜻·주의사항은 공개된 기존 자료를 그대로 표시하며, 별도 작성한 6개 편집 가이드는 사용 상황·뉘앙스·피할 사용·중국어 예문·한국어 해석을 제공한다. 실제 게시물 인용이나 인기 지표로 표시하지 않는다. 알 수 없는 표현에 규칙만으로 예문을 만들어 넣지 않는다.

예문을 연습칸으로 가져와 직접 수정한다. 제목·표지는 100자 이내 교체, 본문은 10,000자 이내 추가이며 적용 대상을 명시한다. 내 계정 미설정 상태에서도 연습할 수 있고 기존 계정 갱신 경로를 유지한다. 저장 전 입력은 화면 상태이며 선택/AI 입력 변경·새로고침 시 초기화됨을 안내한다. AI 한국어 확인본은 수동 수정에 자동 번역되지 않음을 안내한다.

기존 비공개 기획 저장과 서버 검증을 재사용한다. 공급자 호출·가격 변경·DB 마이그레이션 없음. 테스트는 편집 가이드 선택, 원문 미지원 처리, 본문 추가 보존, 실제 가져오기 후 본문 확인을 포함한다.
