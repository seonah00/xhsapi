# 0064. REDi 글쓰기용 공용 사전 선택 전달

2026-11-25 사용자 승인. XHS 공용 사전의 공개 표현·태그를 로그인한 조직 구성원이 검색어 일치로 각각 최대 5개 추천받고 최대 10개 선택한다. 선택은 검색어가 바뀌어도 유지한다. 뜻·사용법(있는 경우)·주의사항을 확인하고 JSON 복사로 REDi에 가져온다. 비공개 모음, 공유주소, 인증정보는 전달하지 않는다.

XHS의 COOP same-origin을 유지하기 위해 cross-origin popup postMessage 대신 명시적 복사·붙여넣기를 사용한다. REDi는 allowlist/길이/개수 검증을 적용하고 가져온 자료의 출처 진위를 서버 인증했다고 주장하지 않는다. 사용자가 항목을 제외할 수 있고 선택 없이 기존 작성이 가능하다. 선택한 자료만 기존 AI 요청에 데이터로 전달한다. 대본의 태그는 발화에서 분리하고 사용된 항목은 원문 일치로 판별한다. 추가 AI 추천·수집은 없다.

한계: 의미 검색이 아닌 단어 일치 추천, 앱 재접속 영속 선택 없음, 미등록 사용법 자동 생성 없음. AI 생성 품질은 유료 호출 없이 모의 검증한다.
