# 0053 — 홈·성과·계정의 모바일 조작과 학생 안내

2026-10-23. 운영375px에서 계정버튼38px, 성과입력38px/14px 확인. 홈은 계정쿼리를 사용하지 않는데 계정목록이 ‘이 계정 기준으로 홈 보기’라고 안내했다. 성과에는 모바일과 맞지 않는‘오른쪽’, 주메뉴에서 제외된 기획 연결 절차, 미구현CSV/자동연동예고가 남았다.

홈·성과/하위·계정/하위에 mobile-dashboard 범위를 적용한다. 작은화면 텍스트입력16px/44px, 링크·버튼·summary·체크선택label44px. min-width0으로 카드/fieldset 표가 화면을 밀지 않게 한다. 표는 가로스크롤을 유지하고 보이는 안내·키보드포커스·영역이름 추가.

계정목록의 작동하지 않는 홈 선택안내를 실제 account필터를 처리하는 성과화면으로 변경한다. 사용자에게 프로필버전숫자 대신 수정일·저장완료·변경사항저장을 안내한다. DB버전·동시성제어·이전자료보존은 그대로다. 개인정보삭제·AI동의·지표누락안내는 유지한다. 예산/제공자/수집 정책 변경없음.
