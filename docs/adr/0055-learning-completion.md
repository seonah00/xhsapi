# 0055. 사전 선택 유지와 사례 기반 작성·검토 연결

2026-10-25 사용자 승인 범위: 1차 선택 유지/홈 이어쓰기/완성 미리보기/사전 가독성, 2차 소수 관리자 검토 사례 및 기존 검토·성과 경로 보완. 사례 공개는 관리자가 검토 후 수행한다.

- 선택은 사용자·조직·모드별 브라우저 탭 sessionStorage에 보관한다. 서버는 글쓰기에 전달된 ID 소유권을 재검증한다. 현재 선택을 임시 본문과 결합하며 태그를 조용히 버리지 않는다.
- 한국어 확인 상태는 중국어 제목·표지 문구·본문·태그의 정확한 값과 대조한다. 수정 시 확인본을 유지하고 재검토를 요구한다. 20자는 앱 권장 기준이며 기존 입력 제한 200자를 플랫폼의 공식 제한으로 주장하지 않는다. 미리보기는 표지 문구이며 타인 미디어를 다운로드하지 않는다.
- 기존 기획(plan_versions) 검토·성과 연결은 유지한다. 새 writing_reviews는 특정 writing_versions를 DB 트리거가 복사하며 개인 메모·사전 항목·나중 초안을 제외한다. 작성자와 배정된 담당 강사만 읽고, 철회 이후 강사의 접근을 차단한다.
- 관리자 작성 사례는 비공개 저장 → 명시적 검토 후 공개, 본문 수정 시 검토를 무효화한다. 실제 검토하지 않은 게시물을 공개 사례로 만들지 않는다. 적용 질문 답변은 새 글의 개인 참고 메모에 추가하고 기존 임시 내용을 보존한다.
- 성과는 본인 작성물의 특정 버전을 참조한다. 원본/이력은 변경하지 않는다. 외부 AI·수집·예산·정기 실행 제어를 변경하지 않는다.

참고 구조: https://tempo-guides.vercel.app/mac01 의 비교·해석·체크·적용 순서. 문장·사례 수치 복제 없이 XHS 학습 흐름에 맞게 구성.
