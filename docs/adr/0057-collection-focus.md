# 0057 게시물·해시태그·표현 중심 운영

2026-10-26 사용자 요청: 분산된 글쓰기/작성 이력/사례 가이드를 제외하고 게시물 탐색·해시태그·표현에 집중한다. 해당 web 라우트와 server actions 및 연결 컴포넌트를 제거하고 직접 URL도404로 종료한다. 홈의 작성본 조회와 이어쓰기, 사전의 생성/작성 도구 및 작성물 검토 연결을 제거한다. 해시태그/표현 목록은 뜻·사용 상황·주의·예문·복사·내 모음 저장·관련 게시물로 단순화한다.

메뉴는 홈/게시물 탐색/해시태그/표현/내 모음이다. 해시태그와 표현은 동일 사전의 종류 필터를 사용하며 query별 현재 메뉴도 구분한다. 내 모음의 검색/분류/편집/예문/페이지는 유지한다.

일반 게시물 검색은 한국어 후보 확인과 기존 자료의 제목/본문 일부/태그/수집 검색어 매칭을 유지하되 신규 자동 수집을 요청하지 않는다. 기존 자동 승인 설정/비용/예약/정기 스위치는 변경하지 않는다. 관리자의 별도 견적 수집 경로는 기존 권한·동의·비용 게이트를 유지한다. 정기 갱신은 이번 범위에서 활성화하지 않는다. 관련 게시물 버튼은 GET 조회이며 해당 태그의 실제 포함을 보장하거나 샤오홍슈 전체 검색량을 뜻하지 않는다.

사용자는 작성물과 이력 삭제도 요청했다. 다른 학생의 저장 자료까지 포함할지는 명확하지 않아 기능 제거와 분리해 범위를 질문했다. 범위 답변 전에는 DB 자료를 영구 삭제하거나 과거 migration/core 삭제 처리를 제거하지 않는다. 보존 중인 기록에 대한 개인 데이터 삭제 요청 기능과 RLS를 유지한다. 삭제 범위 확정 후 별도 결과를 기록한다.

기존 작성/사례 web 전용 E2E는 기능 제거에 맞게 제거, 역사적 core/DB 격리/삭제 테스트는 유지한다. 대체 학생 PC/mobile 흐름에서 새 홈/퇴역 링크 없음/관련 게시물 매칭/옛 URL404/axe/넘침 검증을 추가한다. 검토 공개 사전 테스트는 가져오기·비공개정보 미노출·학생 저장·복사·검색으로 갱신한다.
