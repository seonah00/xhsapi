# ADR 0061: 주제별 25건 일회 수집

2026-11-02 사용자 승인: 맛집/뷰티 각 최대25건, 총50건. 사용자가11월USD한도0.65를 등록했다. 관리자 수량25/50을 서버검증하고 견적·실행 입력 해시에 포함한다. 공급자 maxResults/maxItems 모두25로 제한한다. 25건은 검증된50건 실행상한을 그대로 예약하며 0.5회로 할인 추정하지 않는다. 두 작업 합계 최대0.65, 최근7일/최신순/다른정렬보충없음. 예산증액·정기활성화·AI·과거불명작업재시도 없음. 결과가 부족하거나 중복이어도 추가 유료 요청하지 않는다. 원문 확인 전 신규 자료는 탐색 비공개를 유지한다.
