# ADR 0036: 학생 비용 안내와 원문 이동

- 비용·조직 예산·견적 금액은 관리자 화면에만 표시한다. 외부 전송 범위 동의와 서버 예약/한도/단가 검증은 유지한다. 학생에게는 이용 불가 및 처리 상태를 설명한다.
- 공통 확인은 서버에서 조직 역할을 다시 확인한다. 공용사전은 서버가 확인한 역할로 표시를 분리한다. 금액 자체가 비밀 값이 되는 새 API 권한 정책을 도입하는 변경은 아니다.
- 상세 화면 표지도 탐색 카드와 같은 원문 리디렉션을 사용한다.
- 다른 공급자가 수집한 동일 플랫폼 게시물의 유효 링크를 재사용할 수 있다. 조직, 데이터 모드, 게시물 ID와 만료 조건을 모두 검사한다. TTL을 연장하거나 만료된 토큰을 사용하지 않는다.
- 원문 링크가 있는 저장 게시물만 고르는 필터를 제공한다. 플랫폼 로그인이나 삭제 여부를 보장하는 필터는 아니다.
- 링크가 없는 데이터의 신규 재수집은 기존 유료 수집 경로와 승인 한도에 따른다. 화면 수정으로 전체 과거 링크가 복구됐다고 표시하지 않는다.
