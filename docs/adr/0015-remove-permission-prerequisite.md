# 0015 — 별도 이용 허가·증빙 승인 조건 제거

2026-10-07 사용자 요청: 계약 증빙 업로드와 별도 허가 승인 절차를 제거한다.

- RedFox/Apify 실행과 검색 엔드포인트 선택은 provider_permissions에 의존하지 않는다.
- 관리자 승인·증빙 업로드 양식을 제거한다. 과거 기록과 증빙 파일은 이력 보존을 위해 삭제하지 않는다.
- 검색 결과의 제한된 발췌·안전한 미리보기 URL은 허가 기록 없이 저장·표시한다.
- Apify 보완의 permission_id는 nullable로 바꾸며 신규 저장은 null이다. 보관은 최대 24시간이다.
- 보완 자료 읽기는 활성 조직 멤버십과 만료 시각으로 제한한다. 다른 조직에는 노출하지 않는다.
- 서버 secret, 환경/조직/기능 스위치, 단가 verified, 고정 Actor 빌드, 견적·동의·예산 예약, 멱등성과 unknown_outcome 재전송 금지를 유지한다.
- 이번 실제 검증의 사용자 한도는 검색 0.30 CNY + 표지 3 USD다. 이미 검색 0.18 CNY를 정산했으며 추가 검색을 자동으로 실행하지 않는다.
- 원본 다운로드, P1/P2 자동 활성화, 로그인·쿠키 우회는 범위 밖이다. 기존 음성 전문 보관 정책도 확대하지 않는다.

마이그레이션 18과 앱을 함께 배포해야 한다. 기존 승인/철회 기록은 새 실행을 막는 스위치가 아니며, 중단에는 조직 전체 중지 스위치를 사용한다.
