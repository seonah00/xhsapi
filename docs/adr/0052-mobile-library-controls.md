# 0052 — 사전·글쓰기 모바일 입력과 조작 크기

2026-10-23. 운영 관리자 세션375px에서 공용사전/내 사전/글쓰기/작성 이력의 입력 글자14px, 검색창 높이36~38px 확인. 공용사전 보조 검색은 한 줄 flex여서 버튼이 좁아짐.

사전·글쓰기 경로의 서버 layout에만 learning-library 범위를 적용한다. 767px 이하에서 텍스트 입력16px/높이44px, 버튼·summary·버튼형링크 최소44px. 긴 문자열 줄바꿈과 fieldset 최소폭0으로 좁은 화면을 보호한다. 공용사전 보조검색은 모바일 세로/데스크톱 두열, 바로가기 줄바꿈.

저장·AI·권한·동의·예산·수집 로직은 변경하지 않는다. 모바일 폰트로 인한 실제 iOS 줌 동작은 물리기기 미검증이며 브라우저 viewport만으로 보장하지 않는다.
