# 0049. 한국어 날짜 표시를 서버와 브라우저에서 동일하게 구성

2026-10-23 · Accepted

운영 탐색의 React418 텍스트 불일치를 여행·외출 카테고리에서 반복 재현했다. 운영과 같은 Node22.23.2의 `Intl.DateTimeFormat('ko-KR')`는 시간대를 `PM`/`AM`으로 표시하지만 브라우저는 `오후`/`오전`을 표시한다. 같은 게시물 카드의 관찰 시각이 달라 초기 HTML을 브라우저가 다시 그렸다. Node26의 로컬 단위 검사만으로는 이 차이를 발견하지 못했다.

`fmtDate`는 Asia/Seoul의 숫자 날짜·24시간 부분을 `formatToParts`로 구한 뒤 한국어 날짜와 오전·오후 문자열을 직접 구성한다. 시간대 계산은 Intl에 유지하며 브라우저 시간대·ICU 번역 문자열에 의존하지 않는다. 오류 숨김이나 hydration 경고 무시를 적용하지 않는다. 날짜 전용·기존 미확인 표시와 자정/정오의 12시간 표기를 유지한다.

합성 날짜 단위 회귀와 영어/미국 시간대 학생 브라우저 회귀를 추가했다. 실제 수집·AI·예산·정기수집 정책 변경은 없다. 검증 근거는 docs/tdd/0049-date-hydration.test-spec.md를 참조한다.
