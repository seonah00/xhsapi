# 0041 공용 키워드 정기 재수집·장기 집계

2026-10-20. 사용자는 정기 재수집/장기 추적 구현을 요청했고 예상 활성 수강생100명을 확인했다. 신규 예산/유료 반복 실행은 아직 승인하지 않았다.

- 관리자만 공용 검색어 최대30개/모드, 1·7·30일 주기와 최대31일 승인 기간을 저장한다. 등록 기본은 중지. 기존 자동검색 승인/캐시/견적/월한도/예약/실행 게이트를 그대로 사용한다.
- 워커60초 tick에서 행 잠금 후 원자적 검색접수. 실패/불명/승인만료/한도/기능중지 시 중지한다. 불명작업 자동재실행/예약해제 없음. 중지 시 진행작업을 취소하지 않고 결과집계는 마무리한다. 밀린 회차를 몰아 실행하지 않는다.
- 성공 검색의 원래 job ID별 1개 집계만 저장한다. 캐시재사용은 새 관측으로 중복저장하지 않는다. 동일 결과의 기간별 원문/ID/URL/토큰은 장기보관하지 않는다. 집계(정확태그수/전체표본/작성자수/정확반응중앙값/날짜범위)만365일 보관한다. 원본 만료/누락은 사용0으로 오인하지 않고 중지한다.
- 과금 견적의 공급자/endpoint/Actor/build와 집계방식버전으로 비교가능성을 판단한다. 서로 다른방법 또는 표본10/태그3/작성자2 미만에서는 증감값을 표시하지 않는다. 전체플랫폼 검색량·유행·조회수순위로 표현하지 않는다.
- 조직멤버는 집계읽기만 가능. 모든 변경은 서버 관리자재확인/감사기록. mode와org격리. 새일정이없으면 배포해도유료실행없음.
- 모의테스트와 CI 검증 후 운영 배포. 유료 주기활성화는 대상목록과새예산승인후별도.
