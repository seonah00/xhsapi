# 0051. 게시물 우선 탐색과 저장자료 페이지 이동

2026-10-23 · Accepted

모바일 운영 점검에서 카테고리 키워드 분석이 기본 펼침이라 첫 게시물까지 약24,700px를 내려야 했다. 학생의 탐색 여정은 게시물 조회가 먼저이고 분석은 선택적인 보조 활동이다.

탐색의 키워드 분석을 기본 닫힌 native details로 감싼다. JS 없이도 열 수 있고 정확성 안내·태그 검증·사전 저장·AI 동의 과정은 유지한다. desktop/mobile 모두 같은 접기 동작을 사용하여 위치와 접근성 semantics가 일치한다. 조건/페이지 변경 시 key를 바꾸어 다시 기본 접힘으로 시작한다.

기존50건 offset cursor를 그대로 사용해 목록 위아래에 현재 페이지와 이전/다음 GET 링크를 둔다. 총 페이지는 계산하지 않아 알 수 없는 총량을 만들어내지 않는다. 반복 terms와 검색·주제·형식·정렬·기간·원문·작업 범위는 보존하고 quote/auto 액션 상태는 전달하지 않는다. 새 조회나 예산 예약을 실행하지 않는다.

모바일 필터를2열로 줄이고 입력16px·높이44px 이상, 버튼/summary44px 이상을 적용한다. CSS 범위는 탐색으로 한정한다. 학생에게 갱신/관찰 시각·공급자 인기 보조자료·중복 원문필터·정기수집 추이 링크 등 운영 문구를 숨기되 원문 이동/복사, 비교, 사전·글쓰기와 중요한 AI/실사용 한계 설명은 유지한다. 조직·예산·수집 정책을 바꾸지 않는다.

검증 매핑과 제한은 docs/tdd/0051-mobile-discovery.test-spec.md에 기록한다.
