# ADR 0019: 학생 탐색과 게시물 상세

2026-10-07 요청: 학생에게 조회 과금 절차를 노출하지 않고, 외부 원문 404 및 표지 실패를 다룬다.

- 탐색의 새 게시물 조회·견적·동의 UI와 서버 액션은 관리자 전용이다. 학생은 저장된 공유 자료를 무료로 검색한다. 이 변경은 학생 검색마다 자동 과금을 시작하지 않는다. 관리자 사전 승인 예산으로 학생의 자동 검색을 지원하려면 별도 정책(일일 상한·동일 검색 재사용·쿼터)을 구현해야 한다.
- 썸네일은 조직/모드가 일치하는 앱 내부 게시물 상세를 연다. 외부 원문과 제목 검색 링크는 상세 화면에서 명시적으로 제공한다. 게시물 300031 오류는 외부 사이트에서 반환한 404이며, 삭제/접근 제한을 구분할 근거는 없다.
- canonical URL은 기존 설계대로 공개 게시물 식별자이며 xsec_token을 포함하지 않는다. 이를 원문 열림 보장으로 취급하지 않는다. 프로필 주소나 다른 게시물 주소를 공급자가 반환하면 해당 노트의 ID 주소를 유지한다. 재수집 시 canonical URL도 갱신한다.
- 선호 표지가 실패하면 이미 공급자가 제공한 기존 표지 주소를 시도한다. 모든 후보가 실패한 경우에만 관리자 이미지 업데이트 대상으로 집계한다. URL을 추측하거나 우회 프록시를 사용하지 않는다.
- 사용자 사례의 표지 URL 직접 GET은 200/image/jpeg였다. 이는 다른 표지 및 다른 브라우저에서의 로딩 성공을 보장하지 않는다.

검증: 학생 과금 UI 비노출, 관리자 조회, 상세 조직 격리, 원문 링크 유지, 실패한 선호 표지의 대체 이미지 로딩, 공급자의 잘못된 노트 링크 회귀 테스트.
