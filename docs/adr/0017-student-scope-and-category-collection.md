# ADR 0017: 학생 기능 범위와 카테고리 수집

2026-10-07 사용자 요청: 학생의 이미지·정보 업데이트 UI를 숨기고, 해시태그·자료실·표현사전 기능을 제거한다. 탐색 카테고리는 관련 게시물 50건 이상을 목표로 한다.

- 표지·상세 업데이트는 조직 관리자만 접근한다. 화면, 서버 액션, 견적 생성 및 예약 서비스에 역할 검사를 적용한다. 학생은 보완된 표지를 읽을 수 있다.
- 해시태그·자료실·표현사전 페이지, 공개 API, 검토 페이지 및 공유·표현장 저장 액션을 제거한다. 기획 본문의 해시태그 입력과 검색 분류용 내부 데이터는 유지한다. 기존 개인정보와 이력 테이블은 삭제·내보내기를 위해 남긴다.
- 운영 모드의 레퍼런스 분석은 미연결 상태를 명시한다. 데모 규칙 분석은 테스트에서 유지하며 실제 AI 기능으로 표시하지 않는다.
- 카테고리만 선택해도 편집된 기본 중국어 검색어로 견적을 받을 수 있다. 수집 종료 목표는 중복을 제외한 해당 카테고리 분류 결과 50/100건이다. 모든 반환 게시물은 저장하되 관련 없는 게시물은 목표 수에 넣지 않는다.
- 최대 페이지·동의·예산 상한을 유지한다. 카테고리 선택은 무료 저장 자료 조회이며 자동 유료 수집을 시작하지 않는다. 원천 데이터가 부족하면 50건을 보장하지 않는다.

검증: 관리자 실행·학생 직접 URL 차단, 폐기 경로 404, 카테고리 단독 견적 E2E 및 분류 적합 결과만 세는 워커 회귀 테스트.
