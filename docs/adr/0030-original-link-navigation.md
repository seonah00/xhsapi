# ADR 0030 — 원문 이동과 제목 검색의 구분

사용자는 제목 검색이 아닌 해당 게시물의 콘텐츠로 바로 이동하기를 요청했다. 현재 운영 DB의 유효 note_access_links는 0건이며 제목 검색 URL을 원문 링크로 간주할 수 없다.

- 유효 공유 링크가 있으면 탐색 썸네일과 “게시물 원문 보기”는 로그인·조직 확인 후 기존 원문 리디렉션 경로로 이동한다.
- 공유 링크가 없으면 로컬 상세의 원문 연결 안내를 표시한다. 제목 검색은 “샤오홍슈에서 제목 검색”이라는 보조 동작으로 분리한다. 토큰 없는 주소나 추측한 접근 토큰으로 우회하지 않는다.
- 관리자는 해당 게시물 ID와 일치하는 공개 전체 공유 URL을 연결할 수 있다. 기존 호스트·경로·xsec_token 검증, 24시간 TTL, 별도 보호 저장소를 사용한다. 다른 게시물·계정·검색·단축 주소는 거부하며 학생은 변경할 수 없다. 원문 주소는 AI·노트 JSON에 포함하지 않는다.
- 원문 삭제·로그인 요구·공유 링크 만료는 외부 플랫폼 상태에 따라 발생할 수 있다. 모든 저장 게시물의 원문 재생을 보장하지 않는다. 공급자가 유효 링크를 반환하지 않는 경우 실제 공유 주소가 필요하다.

검증: 원문 리디렉션·썸네일 대상·만료 안내 E2E, 관리자 역할·게시물 일치·조직 격리 DB 테스트.
