# ADR 0045: 사전 선택 동선·독립 글쓰기·원문 연결 표시

2026-10-21 · 채택

공용사전의 활용 패널이 모바일에서 긴 목록 아래에 있고, 직접 글쓰기보다 AI 폼이 먼저 나왔다. 성과 비교 표는 모바일 grid 최소폭을 밀어 화면 밖으로 넘쳤다.

- 공용사전 선택 수·활용 이동 버튼을 모바일 하단에 고정한다. 같은 컴포넌트의 선택·작성 상태를 유지하면서 패널로 이동하고 키보드 포커스를 준다. 페이지 메뉴에는 하단 여백을 둔다.
- 직접 작성이 기본이다. AI 도움은 키보드로 이동 가능한 탭으로 분리한다. 양쪽 패널을 유지하여 탭 전환으로 임시 글·AI 입력·동의 상태를 초기화하지 않는다. 실제 조건 변경 시 기존 미리보기 무효화는 유지한다.
- 독립 글쓰기는 실제 존재하는 내 사전 선택 경로와 항목 없는 직접 작성을 안내한다.
- 성과 grid 자식에 min-width:0을 적용하고 큰 표의 가로 이동은 표 컨테이너 안에서만 일어난다.
- 유효 공유 정보가 있을 때만 로그인된 사용자가 원문 연결 주소를 복사한다. 복사 주소는 같은 origin의 인증된 original 경로이며, 현재 TTL 저장소의 공유 주소로 리디렉션한다. 샤오홍슈 접근 토큰을 HTML·AI·로그에 추가 노출하지 않는다.
- 접근 정보 없는 canonical 기본 주소는 보조 펼침 영역으로 분리하고 접근 보장을 하지 않는다. 원문 연결이 만료되면 안내한다. 클립보드 실패는 사용자에게 표시한다.

새 유료 호출, TTL 연장, 기존 unknown_outcome 재실행, 예산 증액, 정기 수집 활성화는 하지 않는다. 원문 링크 UI가 새 공유 주소 수집이나 외부 로그인 성공을 보장하지 않는다.
