# 인계 문서 (2026-10-09 기준)

## 최신 변경 (ADR 0023, 2026-10-09)

기획실 촬영표에 구도·장면 자막·준비물·촬영 완료 체크와 순서 이동을 추가했다. 기존 장면/메모만 있는 기획과 AI 제안도 호환한다. 최종본·Markdown·JSON·제출 검토 화면에 촬영 준비 정보가 전달된다. 장면 자막도 문구 점검에 포함하며 자막 수정 시 점검 해시가 달라진다. 유료 API 호출과 새 마이그레이션 없음. 검증 및 배포 결과는 해당 작업 보고서 참조.

표현 활용 설명과 사전 사용 이력은 여전히 후속 후보다.


## 최신 변경 (ADR 0022, 2026-10-08)

공용사전 검색·선택과 Gemini 초안은 운영에서 확인됐다(공개477개, 1회 실제 생성 성공). 이전 표현사전 삭제 기록과 별개로 사용자가 새 공용사전 도입을 요청했다.

공용사전 → 비공개 기획 저장을 추가했다. 사전 항목만으로도 시작하며, AI 결과가 있으면 제목 후보·본문·한국어 확인본·태그와 직접 입력한 표지 문구를 저장한다. 계정 설정 없는 경우 새 창 설정 후 목록 갱신. 기획실에서 저장 당시의 뜻·주의점·메모와 기존 촬영표를 사용한다. 추가 AI 호출 없음. 배포/검증 결과는 작업 보고서 확인.

REDi는 범용 아이디어·비주얼·제목·대본·성장 플래너를 담당하고, 이 앱은 검토 사전 활용과 개별 게시물의 문구·촬영 실행 작업지에 집중한다. 전체 기능 재구현이나 기존 기능 삭제는 하지 않았다.

현재 우선 잔여 작업: OpenAI 상세 분석/기획/회고 활성화와 품질 검증, 학생 자동 수집 운영 예산 설정, 실패 표지와 유효 공유 링크 갱신. 다음 개발 후보는 선택 표현의 자연스러운 활용 설명, 장면별 준비물/촬영 완료 체크, 사전 활용 이력이다.

아래 과거 기록보다 이 절을 우선한다.

## 최신 변경 (ADR 0021, 2026-10-07)

제목·본문·태그의 상세 분석 8개 항목, 실제 문구 인용·한국어 설명·근거 검사, 분석 요약을 활용한 live 기획 제안, 본인 성과의 live AI 가설·실험 제안을 구현했다. 기획 자동 저장의 레퍼런스 연결 유실과 사실 변경 후 옛 제안 적용도 방지한다. 기존 v1 결과는 유지한다. 이번 변경의 검증/배포 상태는 `docs/AI_WORKFLOWS_VALIDATION.md` 참조.

직전 v1 실제 연결 검증은 gpt-4.1-mini 1회 성공, 앱 원장 USD 0.0112 settled, AI01은 이후 suspended 상태다. 이 기록은 새 상세 분석/기획/회고의 실제 응답 품질 검증이 아니다. v2는 출력 6,000 토큰으로 확대돼 마이그레이션 23과 새 출력 상한의 단가 재검증이 필요하다. 기존 키·모델을 유지해도 자동 활성화되지 않는다.

### 남은 기능/운영 작업 (현재 우선)

1. 상세 분석·기획·회고 v2 실제 소량 품질 검증과 운영 AI 일일/기간 예산 확정. 구현된 기능을 실제로 켜는 작업은 별도다.
2. 학생 자동 검색은 구현 완료, AUTO_REFRESH_ENABLED와 관리자 후원 정책(기간·회당/일일 상한) 활성화가 남음. 기존 일회성 승인은 반복 예산이 아님.
3. 표지·원문: 실패 표지 관리자 보완/공유 링크 TTL 구현 완료. 새 공유 링크의 수집·실제 열림 확인, 만료 자료 갱신 필요. 샤오홍슈 차단/삭제 게시물의 열림은 보장 불가.
4. AI 문맥 점검은 mock만 지원. 음성 문안은 RF13/RF14 가격·운영 계약 검증이 남음. OCR·댓글은 미활성/후순위. 영상 분석·자동 게시·타인 원본 다운로드는 이번 범위 밖.
5. 운영 백업 자동화, 비밀번호 재설정/학생 삭제 실운영 확인, 탐색 쿼리 성능 개선이 남음.
6. 해시태그·자료실·표현사전의 독립 화면은 사용자 요청으로 제거한 범위이며 재구현하지 않는다. 분석 안의 태그 해석은 유지한다.

아래 과거 상태보다 이 절과 ADR 0021을 우선한다.

## 최신 구현 상태 (ADR 0020)

공유 링크 보존·만료 처리, 운영자 부담 학생 자동 검색, 실제 OpenAI 텍스트 레퍼런스 분석을 구현했다. 활성화 설정 전에는 실제 자동 검색·AI 호출이 실행되지 않는다. 2026-10-07 사용자 확인: OpenAI API 키는 아직 미등록이며 구현·테스트 후 등록 예정. 기존 원문 404의 해결을 보장하지 않으며 신규 공유 정보는 다음 승인된 수집에서 확보한다. 과거 기록의 “AI 미연결”은 아래 구현 이전 상태다.

## 이전 기능 범위 (ADR 0017)

- 학생 화면에서 이미지·정보 업데이트를 제거하고 관리자 전용으로 제한했다.
- 해시태그·자료실·표현사전 화면/API/공유 액션을 제거했다. 과거 데이터와 내부 검색·분류 서비스는 보존한다.
- 운영 레퍼런스 분석은 AI 미연결로 사용 불가. 데모 규칙 분석만 구현돼 있다.
- 카테고리 단독 수집 견적과 카테고리 적합 결과 50건 목표를 구현했다. 전체 카테고리 운영 데이터 50건 확보는 별도 수집 작업이며 아직 완료하지 않았다.
- 남은 우선순위: 카테고리별 데이터 확보·분류 품질 → 실패 표지 관리자 보완 → AI 레퍼런스 분석 연결 → 기획 생성·성과 해석 AI 연결. 음성 문안은 단가/실행 설정 검증 필요. OCR·댓글·자동 갱신은 후순위이며 꺼져 있다.
- 직전 운영 실검증: Apify 표지 1건 성공, 앱 원장 USD 0.06 정산, 반환 미리보기 HTTP 200/WebP. 韩国旅行 검색 연결 60건 확인.

아래 이전 단계의 상태보다 이 절과 최신 ADR을 우선한다.

## 2026-10-07 최신 변경 — 별도 허가·증빙 절차 제거

ADR 0015가 아래 과거 허가 관련 절차보다 우선합니다. 운영자가 승인한 단가, API 키·고정 빌드, 환경·조직 스위치, 통화별 예산을 설정하면 사용자 비용 확인과 동의 후 실행합니다. 별도 provider_permissions 기록이나 증빙 파일은 필요하지 않습니다. 관리자 화면의 승인 양식도 제거했습니다. Apify 보완은 최대 24시간 보관하며 조직 격리와 만료를 유지합니다. 마이그레이션 18 적용이 필요합니다. 기존 허가 기록은 이력이며 중단에는 전체 중지 스위치를 사용합니다.

이번 실검증: RedFox 검색 3페이지/60건 성공, 0.18 CNY 정산. Apify 표지 수집은 아직 미실행이며 승인 한도는 최대 50건/3 USD입니다.


다른 에이전트(Codex 등)나 사람이 이어서 작업할 때 먼저 읽는 문서입니다. 규칙은 `AGENTS.md`, 제품 명세는 `docs/XHS_STUDIO_DEVELOPMENT_SPEC.md`, 최초 지시는 `docs/CODEX_START_PROMPT.md`, 결정 기록은 `docs/adr/0001~0013`에 있습니다.

## 3. 알려진 문제와 보완 후보 (우선순위 순)

1. **표지 이미지가 안 보임**: 이전 RF02 표지 요청에서 403이 관측됐습니다. 당시 t를 만료로 해석했지만, 새 실검증에서 t 이후에도 200이 확인돼 해당 추정을 제거했습니다(ADR 0014). 실제 로딩 실패 시 내부 썸네일을 보여 줍니다.
   - 남은 경로: RedFox에 최신 서명 주소를 받을 방법이 있는지 문의. Apify SocialDataX의 선택 노트 상세·표지 보완을 로컬 구현했습니다(ADR 0012, 미배포). 공급자를 바꿔도 서명 URL 만료는 해결되지 않을 수 있습니다.
   - 하지 말 것: 차단·토큰 우회, 비공식 로그인·쿠키 공유, `videoDownload/xhs`(워터마크 제거 다운로드).
2. **원문 링크 오류**: RF01/RF02 링크에 `xsec_token`이 없어 샤오홍슈가 막을 수 있습니다. 카드에 "제목으로 찾기"를 추가해 두었습니다.
3. ~~live 노트 주제 분류 없음~~ → 키워드 분류기(`keyword-v1`, 신뢰도 low)로 해결했습니다(ADR 0011). 키워드 목록 보강과 이미 저장된 노트의 소급 분류가 남아 있습니다.
4. **RF08(계정 노트 목록)·RF10(인기 계정)**: 파라미터 이름은 공식 Python SDK(`github.com/redfox-data/redfox-python-sdk`)에 나옵니다.
   - RF08: `redId|userid, offset, sortType, publishTimeStart/End`
   - RF10: `dateType, rankDate, type`

   응답 예시와 단가를 받기 전까지 `parameter_unverified`로 막아 둡니다.
5. **RF09(노트 상세)** 어댑터가 미구현이고 `ProviderNotReadyError`를 던집니다. 문서 기준 필드는 RF02와 같습니다.
6. **RF13/RF14(음성 문안) 단가 미확인**: 실행하려면 단가 등록과 `TRANSCRIPT_ENABLED=true`가 필요합니다. 이제 RF02가 노트 형식(영상/이미지)을 주므로 영상 노트를 고를 수 있습니다.
7. ~~배포 중 서버 액션 불일치~~ → 오류 경계가 감지해 한 번 자동 새로고침하도록 해결했습니다(ADR 0011).
8. **지연**: `withUser` 왕복을 3번에서 1번으로 줄였습니다(ADR 0011). Railway와 Supabase의 지역 일치는 여전히 운영자가 확인해야 합니다. 탐색 페이지의 쿼리 수 줄이기는 남아 있습니다.
9. **운영 미확인 항목**: 보안 헤더, 관리자 비밀번호 재설정 링크, 학생 데이터 삭제를 실제 환경에서 아직 확인하지 않았습니다(`docs/DEPLOY.md` 점검 절차).
10. **백업 자동화 없음**: `docs/OPERATIONS.md` §5 권고만 있습니다.
11. **오래된 문서**: `docs/P0_REPORT.md` 일부(로컬 shim 기준 설명)는 배포 이전 시점의 서술입니다. 최신 사실은 이 문서와 ADR 0009·0010입니다.
12. **미확인 RedFox 문서**: DCZW5V7A, 9UHXOXSF, tool/QPNFJRG1. 수용 테스트 문서도 받지 못했습니다.

## 4. 작업 방법

### 50/100건 목표 수집과 표지 일괄 보완 (2026-10-07, ADR 0013)

- 외부 조회는 기본 50건, 선택 100건 목표입니다. RF02 offset 0/20/40…을 최대 5/7페이지까지 조회하고 중복을 제외합니다. 목표 도달·결과 종료·같은 페이지 반복·상한 도달 시 종료 이유를 표시합니다. 공급자 결과가 부족하면 50건을 보장하지 않습니다.
- 탐색은 페이지당 50건 표시합니다. 표지가 없는 현재 페이지 노트 최대 50건을 Apify로 일괄 보완하는 별도 USD 견적 화면을 추가했습니다. 자동 과금 없이 학생이 대상·총비용을 확인합니다.

## 검색·이미지 업데이트 (ADR 0016)

韩国旅行 실제 검색은 3페이지/60건을 확보했다. 마이그레이션 19로 검색어와 반환 게시물을 연결하여 제목/태그에 검색어가 없는 결과도 보존한다. 저장 자료 검색과 새 게시물 조회를 구분한다. 이미지 업데이트에는 브라우저 로딩 실패도 포함하며 자동 과금하지 않는다. AP01 요금은 최대 0.06 USD/run으로 등록했고 사용자 승인 예산은 오늘 3 USD이며 반복 예산이 아니다.

## 최신 탐색 변경 (ADR 0018)

썸네일에서 원문을 새 탭으로 연다. 검색창의 새 게시물 검색은 해시태그 기호를 정리한 뒤 견적·동의·수집으로 이어지며 완료 시 이번 작업 결과로 자동 갱신한다. 저장된 게시물 검색은 무료로 유지한다. 새 검색 결과는 작업 소유자·조직·모드로 격리한다. 사용자가 추가 1.20 CNY를 승인했고 뷰티·일상·육아·패션 검색은 각각 3페이지/60건으로 성공했다. 실제 정산은 각 0.18 CNY, 합계 0.72 CNY다. 운영 전체 카테고리 보유량은 뷰티 80·일상 101·육아 66·패션 71·맛집/카페 83·여행/외출 73건(추가 검색·기간·형식 필터 적용 전)이다. 이번 수집은 Apify 표지 보완을 포함하지 않는다. 코드 20abaf5 배포 및 CI 단위 138·DB 140·E2E 20개 통과를 확인했다.

## 학생 탐색·원문 오류 대응 (ADR 0019)

탐색 유료 수집은 관리자 UI와 액션으로 제한했다. 학생 검색은 공유 저장 자료만 조회하며 자동 외부 조회는 아직 미구현이다. 썸네일은 내부 게시물 상세를 열고 원문/제목 검색 링크를 제공한다. 기존 노트 URL에는 xsec_token이 없으므로 원문 404가 해결됐다고 주장하지 않는다. 선호 표지가 실패하면 공급자가 제공한 기존 표지 주소를 시도한다. 둘 다 실패한 경우 관리자 보완 대상이다.

## 공유 링크·자동 검색·AI 분석 (ADR 0020)

- 원문 공유 URL을 service 전용 테이블에 TTL 24시간으로 분리 저장한다. tokenless canonical은 원문 버튼에 직접 쓰지 않는다. 새 링크는 이후 승인된 수집 때 확보한다.
- 학생 자동 검색: 관리자 승인 기간/건당 상한/일일 제한/검색 캐시/동시 중복 방지 구현. 초기 꺼짐, AUTO_REFRESH_ENABLED 및 관리자 설정 필요. 기존 일회성 수집 승인은 반복 승인으로 승계하지 않는다.
- 실제 OpenAI 텍스트 레퍼런스 분석 구현. 초기 미활성: worker OPENAI_API_KEY, web/worker LLM_MODEL·LIVE_LLM_CALLS_ENABLED, 모델별 AI01 단가와 USD 예산 필요. 단가는 pnpm price --provider openai로 등록하며 임의 가격을 넣지 않는다.
- 남은 후속 범위: 새 공유 링크의 실제 수집·열림 확인, 자동검색 운영 상한 설정, AI 모델/단가 선택·실응답 검증. 기획 생성·성과 해석 AI, 음성 문안 실운영, OCR·댓글, 백업 자동화는 아직 미구현/미활성이다.
