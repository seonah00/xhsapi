# 상세 분석·기획·회고 검증 (ADR 0021)

## 범위

- 상세 레퍼런스 8개 항목과 원문 부분 문자열 검증, 자료 부족 처리, v1 표시 호환.
- 분석을 활용한 기획 제안: 사실 입력 필수, 본인 자료 격리, 생성/적용 분리, 사실 변경 검출.
- 본인 성과 회고: 게시물별 한 기록, 실제 수치 관찰 + AI 가설·실험, 중복·타인 자료 거부.
- 모든 실제 공급자 응답은 가짜 fetch. 이번 개발에서 유료 API 호출 없음.
